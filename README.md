# Hotelgrandspindleruvmlyn.cz

Pracovní návrh webu projektu nového hotelu Grand ve Špindlerově Mlýně (Hotel Grand Špindlerův Mlýn s.r.o.).

Stav: **pracovní návrh ke korekturám**. Stránka má `noindex`, místa k doplnění jsou na webu označená žlutě.

## Struktura

- `index.html` – celý web v jednom souboru, stránky se přepínají přes `#uvod`, `#spolecnost`, `#projekt`, `#historie`, `#otazky`, `#kontakt`
- `img/` – vizualizace z ověřovací studie (asi-metr, 11/2023), historické fotky, situace a ortofoto

## Spuštění

Stačí otevřít `index.html` v prohlížeči. Nic se nesestavuje.

## Před spuštěním na vlastní doméně

- doplnit žlutá místa (sídlo, kontakty, provozovatel, foto, datace fotek)
- ověřit licenci ortofota z mapy.cz
- odstranit `noindex` a pruh „Pracovní návrh“
- formulář napojit na skutečné odesílání
